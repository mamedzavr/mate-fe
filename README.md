# Mate front-end

Angular front-end for Mate — a QR menu / restaurant web app with i18n (AZ / EN / RU).

## Stack

- Angular (TypeScript)
- i18n assets under `src` / `docs/assets/i18n`
- Prettier for formatting

## Scripts

```bash
npm install
npm start          # ng serve
npm run build      # ng build
npm test           # ng test
```

Built static output is also present under `docs/` (GitHub Pages–style hosting).

## App areas

- About us, menu / dishes, checkout
- Language switcher (Azerbaijani, English, Russian)
